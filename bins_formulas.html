Cálculo de Clases y Determinación de Distribuciones

Guía de transición: Del cálculo manual a la inferencia computacional en Ciencia de Datos e Ingeniería Industrial

1. Métodos Analíticos para el Número de Clases (\(k\)) y Amplitud (\(W\))

Para construir un histograma a mano, el primer paso es definir el número de intervalos (clases) y su amplitud. En ingeniería, se prefieren tres reglas fundamentales dependiendo de las características del dataset:

A. Regla de Sturges (La más común en textos clásicos)

Ideal para datos con distribución simétrica (cercanos a la normalidad) y tamaños de muestra pequeños a moderados (\(n < 200\)). Subestima el número de clases en muestras muy grandes.

\( k = 1 + 3.322 \cdot \log_{10}(n) \)

Amplitud (\(W\)): \( W = \frac{Rango}{k} \) (donde \( Rango = x_{max} - x_{min} \))

B. Regla de Scott (Enfoque de Ciencia de Datos)

Minimiza el error cuadrático medio integrado. Es óptima cuando los datos provienen de una distribución normal, pero se ajusta mejor a muestras grandes que Sturges.

\( W = \frac{3.49 \cdot S}{\sqrt[3]{n}} \)

Donde \(S\) es la desviación estándar de la muestra. Luego, \( k = \lceil \frac{Rango}{W} \rceil \).

C. Regla de Freedman-Diaconis (Estadística Robusta)

Es la más recomendada en análisis exploratorio de datos (EDA) cuando se sospecha de datos atípicos (outliers) o distribuciones con asimetría severa (ej. Weibull o Lognormal).

\( W = \frac{2 \cdot IQR}{\sqrt[3]{n}} \)

Donde \(IQR\) es el Rango Intercuartílico (\(Q3 - Q1\)).

2. Procedimiento: Histograma "A Mano"

Para identificar la distribución de un parámetro crítico de calidad de forma analógica, los estudiantes deben seguir este algoritmo:

  1. Ordenar: Clasificar los datos de menor a mayor.
  2. Parámetros iniciales: Calcular \(n\) (tamaño de muestra), el valor máximo y el mínimo para obtener el Rango.
  3. Selección de regla: Aplicar Sturges, Scott o Freedman-Diaconis (dependiendo de la presencia de outliers) para definir la amplitud \(W\).
  4. Límites de clase: Construir los intervalos \([L_i, L_s)\). El primer límite inferior comienza en el valor mínimo. El siguiente límite es \(L_i + W\).
  5. Conteo (Frecuencias): Contabilizar cuántas observaciones caen dentro de cada intervalo (Frecuencia absoluta).
  6. Trazado y Diagnóstico Visual: Dibujar las barras.
    • Campana simétrica: Sugiere Normal o t-Student.
    • Asimetría positiva (cola a la derecha): Sugiere Lognormal, Weibull o Exponencial.

3. Validación Computacional e Identificación en RStudio

Una vez realizado el diagnóstico visual manual, utilizamos R para graficar comparativamente las reglas de partición y utilizar la librería fitdistrplus para calcular, mediante Máxima Verosimilitud (MLE), qué distribución teórica se ajusta mejor a la empírica.

# 1. Carga de librerías
# install.packages("fitdistrplus")
library(fitdistrplus)

# 2. Simulación de datos de un proceso (ej. rendimiento de un marinado)
# Ocultamente, simulamos una distribución Weibull (asimetría)
set.seed(123)
datos_proceso <- rweibull(200, shape = 2.5, scale = 15) 

# 3. Comparación de reglas de partición (Bins)
par(mfrow = c(1, 3))

# Histograma con Sturges (Por defecto en R)
hist(datos_proceso, breaks = "Sturges", col = "lightblue", 
     main = "Regla de Sturges", xlab = "Valor", ylab = "Frecuencia")

# Histograma con Scott
hist(datos_proceso, breaks = "Scott", col = "lightgreen", 
     main = "Regla de Scott", xlab = "Valor", ylab = "Frecuencia")

# Histograma con Freedman-Diaconis
hist(datos_proceso, breaks = "FD", col = "lightcoral", 
     main = "Regla Freedman-Diaconis", xlab = "Valor", ylab = "Frecuencia")

# 4. Ajuste formal de la distribución puntual
# Volvemos a un solo gráfico
par(mfrow = c(1, 1))

# Ajustamos dos modelos posibles: Normal y Weibull
ajuste_norm <- fitdist(datos_proceso, "norm")
ajuste_weibull <- fitdist(datos_proceso, "weibull")

# Comparamos matemáticamente usando los Criterios de Información (AIC)
# El valor AIC más bajo indica la distribución correcta
cat("AIC Normal: ", ajuste_norm$aic, "\n")
cat("AIC Weibull: ", ajuste_weibull$aic, "\n")

# Gráfico de diagnóstico (Cullen and Frey graph)
# Ayuda visualmente a saber qué distribución intentar ajustar
descdist(datos_proceso, discrete = FALSE)
