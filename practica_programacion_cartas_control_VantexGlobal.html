Instrucciones generales

Trabajo individual. Elige un solo lenguaje — R (en RStudio) o Python — y úsalo para los ocho casos; no es necesario resolver ambos.

Para cada uno de los ocho casos deberás: (1) importar el archivo CSV correspondiente, (2) calcular la línea central y los límites de control con las fórmulas indicadas, (3) generar la gráfica de la carta con los puntos fuera de control resaltados, y (4) escribir, como comentario al final de tu script, una interpretación breve de lo que observas.

Política de uso de IA en esta actividad. No está permitido usar herramientas de inteligencia artificial para generar el código, los cálculos ni la interpretación. La IA puede usarse únicamente para depurar errores de sintaxis puntuales en tu propio código ya escrito. El razonamiento estadístico y la interpretación deben ser tuyos.

Entrega: un solo script (.R o .py) con los ocho casos resueltos en orden, más las ocho gráficas generadas. Entrega individual al final de la sesión de clase, según indique tu profesora.

Plantilla general: los 5 pasos de cualquier carta de control

Los ocho casos siguen siempre la misma lógica de 5 pasos. Cambian únicamente las fórmulas, constantes y la forma de agrupar los datos.

  1. Importar los datos. Leer el CSV correspondiente (read.csv en R / pd.read_csv en Python).
  2. Calcular el estadístico de cada punto. Según el caso: promedio y rango/desviación por subgrupo, mediana y rango, rango móvil, o proporción/conteo.
  3. Calcular la línea central. Promedio de todos los puntos del paso 2 (o el cociente Σd/Σn en cartas p y u).
  4. Calcular LSC y LIC. Aplicando la fórmula y constantes específicas de esa carta. Truncar LIC a 0 cuando aplique.
  5. Graficar e interpretar. Trazar los puntos, la línea central y ambos límites; resaltar en otro color los puntos fuera de control; escribir la interpretación como comentario.

Caso 1 · Resuelto · Plantilla para X̄–R, X̄–S, Me–R, X–Rm

Diámetro exterior de tapa — Carta X̄–R

La Línea A moldea tapas cuyo diámetro exterior debe mantenerse cercano a 28.50 mm. Se registraron 20 subgrupos de 5 piezas (una hora cada uno). Este caso viene completamente resuelto: úsalo como plantilla para los Casos 2, 3 y 4, que pertenecen a la misma familia (variables, subgrupos, límites constantes).

n: 5m: 20 subgruposObjetivo: 28.50 mm Constantes: A₂=0.577 · D₃=0 · D₄=2.114

# =========================================================
# Caso 1 - Carta X-barra - R (EJEMPLO RESUELTO)
# Vantex Global Packaging Corp. - Planta Celaya
# Diametro exterior de tapa - Linea A
# =========================================================
 
datos <- read.csv("caso1_diametro_xr.csv")
 
# 1) Promedio y rango de cada subgrupo
cols_x <- c("x1","x2","x3","x4","x5")
datos$xbar <- rowMeans(datos[, cols_x])
datos$R    <- apply(datos[, cols_x], 1, function(fila) max(fila) - min(fila))
 
# 2) Gran promedio y rango promedio
Xbb  <- mean(datos$xbar)
Rbar <- mean(datos$R)
 
# 3) Constantes para n = 5
A2 <- 0.577
D3 <- 0
D4 <- 2.114
 
# 4) Limites de control
UCLx <- Xbb + A2 * Rbar
LCLx <- Xbb - A2 * Rbar
UCLr <- D4 * Rbar
LCLr <- D3 * Rbar
 
cat("X-doble-barra =", round(Xbb, 4), "\n")
cat("R-barra       =", round(Rbar, 4), "\n")
cat("Carta X: LSC =", round(UCLx, 4), " LIC =", round(LCLx, 4), "\n")
cat("Carta R: LSC =", round(UCLr, 4), " LIC =", round(LCLr, 4), "\n")
 
# 5) Puntos fuera de control
datos$fuera_control_x <- datos$xbar > UCLx | datos$xbar < LCLx
cat("Subgrupos fuera de control (X):", which(datos$fuera_control_x), "\n")
 
# 6) Graficas
png("caso1_carta_xr_R.png", width = 1400, height = 1000, res = 150)

# =========================================================
# Caso 1 - Carta X-barra - R (EJEMPLO RESUELTO)
# Vantex Global Packaging Corp. - Planta Celaya
# Diametro exterior de tapa - Linea A
# =========================================================
import pandas as pd
import matplotlib.pyplot as plt
 
datos = pd.read_csv("caso1_diametro_xr.csv")
cols_x = ["x1", "x2", "x3", "x4", "x5"]
 
# 1) Promedio y rango de cada subgrupo
datos["xbar"] = datos[cols_x].mean(axis=1)
datos["R"] = datos[cols_x].max(axis=1) - datos[cols_x].min(axis=1)
 
# 2) Gran promedio y rango promedio
Xbb = datos["xbar"].mean()
Rbar = datos["R"].mean()
 
# 3) Constantes para n = 5
A2, D3, D4 = 0.577, 0, 2.114
 
# 4) Limites de control
UCLx, LCLx = Xbb + A2 * Rbar, Xbb - A2 * Rbar
UCLr, LCLr = D4 * Rbar, D3 * Rbar
 
print(f"X-doble-barra = {Xbb:.4f}")
print(f"R-barra       = {Rbar:.4f}")
print(f"Carta X: LSC = {UCLx:.4f}  LIC = {LCLx:.4f}")
print(f"Carta R: LSC = {UCLr:.4f}  LIC = {LCLr:.4f}")
 
# 5) Puntos fuera de control
datos["fuera_control_x"] = (datos["xbar"] > UCLx) | (datos["xbar"] < LCLx)
print("Subgrupos fuera de control (X):", list(datos.loc[datos["fuera_control_x"], "subgrupo"]))
 
# 6) Graficas
fig, axes = plt.subplots(2, 1, figsize=(9, 6.5))
 
colores_x = ["red" if f else "#0a3d62" for f in datos["fuera_control_x"]]

axes[0].axhline(UCLx, linestyle="--", color="red")
axes[0].axhline(LCLx, linestyle="--", color="red")
axes[0].set_title("Carta X-barra - Diametro exterior de tapa")
axes[0].set_xlabel("Subgrupo")
axes[0].set_ylabel("X-barra (mm)")

Fracción de tapas defectuosas — Carta p

Inspección final diaria; el tamaño de muestra varía día con día. Este caso viene completamente resuelto: úsalo como plantilla para los Casos 6, 7 y 8, que pertenecen a la familia de atributos.

n: variable (nᵢ por día)m: 20 días Fórmula: p̄ = Σd/ΣnLímites: p̄ ± 3√(p̄(1−p̄)/nᵢ)
R (RStudio)
# =========================================================
# Caso 5 - Carta p (EJEMPLO RESUELTO - familia de atributos)
# Vantex Global Packaging Corp. - Planta Celaya
# Fraccion de tapas defectuosas - Inspeccion final diaria
# =========================================================
 
datos <- read.csv("caso5_defectuosas_p.csv")
 
# 1) Fraccion defectuosa de cada dia
datos$p <- datos$d_defectuosas / datos$n_inspeccionadas
 
# 2) p-barra global (NO es el promedio simple de los p_i)
pbar <- sum(datos$d_defectuosas) / sum(datos$n_inspeccionadas)
 
# 3) Limites de control PROPIOS de cada dia (n_i variable)
datos$UCL <- pbar + 3 * sqrt(pbar * (1 - pbar) / datos$n_inspeccionadas)
datos$LCL <- pmax(0, pbar - 3 * sqrt(pbar * (1 - pbar) / datos$n_inspeccionadas))
 
cat("p-barra =", round(pbar, 4), "\n")
 
# 4) Puntos fuera de control
datos$fuera_control <- datos$p > datos$UCL | datos$p < datos$LCL
cat("Dias fuera de control:", which(datos$fuera_control), "\n")
 
# 5) Grafica (limites como escalon, ya que varian dia a dia)
png("caso5_carta_p_R.png", width = 1400, height = 700, res = 150)
col_pts <- ifelse(datos$fuera_control, "red", "#c9820a")
plot(datos$dia, datos$p, type = "n",
     main = "Carta p - Fraccion de tapas defectuosas",
     xlab = "Dia", ylab = "p (fraccion defectuosa)",
     ylim = c(0, max(datos$UCL, datos$p) * 1.05))
lines(datos$dia, datos$p, col = "#c9820a")
points(datos$dia, datos$p, pch = 19, col = col_pts)
lines(datos$dia, datos$UCL, type = "s", lty = 2, col = "red")
lines(datos$dia, datos$LCL, type = "s", lty = 2, col = "red")
abline(h = pbar, lty = 2)
dev.off()

Python
# =========================================================
# Caso 5 - Carta p (EJEMPLO RESUELTO - familia de atributos)
# Vantex Global Packaging Corp. - Planta Celaya
# Fraccion de tapas defectuosas - Inspeccion final diaria
# =========================================================
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
 
datos = pd.read_csv("caso5_defectuosas_p.csv")
 
# 1) Fraccion defectuosa de cada dia
datos["p"] = datos["d_defectuosas"] / datos["n_inspeccionadas"]
 
# 2) p-barra global (NO es el promedio simple de los p_i)
pbar = datos["d_defectuosas"].sum() / datos["n_inspeccionadas"].sum()
 
# 3) Limites de control PROPIOS de cada dia (n_i variable)
datos["UCL"] = pbar + 3 * np.sqrt(pbar * (1 - pbar) / datos["n_inspeccionadas"])
datos["LCL"] = np.maximum(0, pbar - 3 * np.sqrt(pbar * (1 - pbar) / datos["n_inspeccionadas"]))
 
print(f"p-barra = {pbar:.4f}")
 
# 4) Puntos fuera de control
datos["fuera_control"] = (datos["p"] > datos["UCL"]) | (datos["p"] < datos["LCL"])
print("Dias fuera de control:", list(datos.loc[datos["fuera_control"], "dia"]))
 
# 5) Grafica (limites como escalon, ya que varian dia a dia)
fig, ax = plt.subplots(figsize=(9, 4.5))
colores = ["red" if f else "#c9820a" for f in datos["fuera_control"]]
ax.plot(datos["dia"], datos["p"], "-", color="#c9820a")
ax.scatter(datos["dia"], datos["p"], c=colores, zorder=3)
ax.step(datos["dia"], datos["UCL"], where="mid", linestyle="--", color="red")
ax.step(datos["dia"], datos["LCL"], where="mid", linestyle="--", color="red")
ax.axhline(pbar, linestyle="--", color="black")
ax.set_title("Carta p - Fraccion de tapas defectuosas")
ax.set_xlabel("Dia")
ax.set_ylabel("p (fraccion defectuosa)")
fig.tight_layout()
fig.savefig("caso5_carta_p_Python.png", dpi=150)
print("Grafica guardada como caso5_carta_p_Python.png")

Salida esperada: p̄ = 0.0524 (límites propios de cada día, en forma de escalón). Días fuera de control: 14 y 15.

Caso 2 · Adapta el Caso 1

Torque de cierre — Carta X̄–S

Estación de ensamble; torque de cierre en N·cm, objetivo 12.0. Subgrupos de n=10 (por eso se usa S en lugar de R).

n: 10m: 20 subgruposObjetivo: 12.0 N·cm Constantes: A₃=0.975 · B₃=0.284 · B₄=1.716

Qué cambia respecto al Caso 1

  • En lugar de R, calcula la desviación estándar muestral de cada subgrupo: en R, sd(fila); en Python, fila.std(ddof=1) (ambas ya usan n−1 en el denominador).
  • Los límites de la carta X̄ usan A₃ (no A₂): LSC = X̄̄ + A₃·S̄, LIC = X̄̄ − A₃·S̄.
  • La carta de dispersión ahora es S, con LSC = B₄·S̄ y LIC = B₃·S̄ (aquí LIC no es cero).
Caso 3 · Adapta el Caso 1

Peso de tapa — Carta Me–R

Verificación rápida de piso; peso en gramos, objetivo 3.20 g. Se usa la mediana en lugar del promedio por su sencillez de cálculo manual.

n: 5m: 20 subgruposObjetivo: 3.20 g Constantes: Ã₂=0.691 (factor de mediana) · D₃=0 · D₄=2.114

Qué cambia respecto al Caso 1

  • En lugar de la media de cada subgrupo, calcula la mediana: en R, median(fila); en Python, fila.median().
  • El rango R se calcula igual que en el Caso 1 (máx − mín de cada subgrupo).
  • Los límites de la carta de medianas usan Ã₂ en vez de A₂: LSC = Mē̄ + Ã₂·R̄, LIC = Mē̄ − Ã₂·R̄. La carta R es idéntica en fórmula al Caso 1.
Caso 4 · Adapta el Caso 1

Viscosidad de resina — Carta X–Rm

Cada lote de resina se prueba de forma individual (no hay subgrupos), por lo que se usa una carta de individuales y rango móvil. Viscosidad en cP, objetivo 450.

Unidad: lote individualm: 25 lotesObjetivo: 450 cP Constantes: 3/d₂=2.66 · D₄=3.267

Qué cambia respecto al Caso 1

  • No hay subgrupos: cada fila del CSV ya es un solo valor individual (x). No calcules promedio ni rango por fila.
  • El "rango" aquí es el rango móvil entre lotes consecutivos: Rmᵢ = |xᵢ − xᵢ₋₁|. En R usa diff(abs(...)) o un bucle; en Python, datos["x"].diff().abs().
  • Los límites de la carta X son: LSC = X̄ + 2.66·Rm̄, LIC = X̄ − 2.66·Rm̄. Los de la carta Rm: LSC = 3.267·Rm̄, LIC = 0.
  • La carta Rm tiene un dato menos que la carta X (24 valores de Rm para 25 lotes): al graficar, usa el eje de lotes 2 a 25.

Muestra fija de 100 tapas por día (a diferencia del Caso 5, aquí n NO varía).

Caso 7 · Adapta el Caso 5 (más simple)

Caso 8 · Adapta el Caso 5

Rebabas por m² — Carta u

Dos moldes alternados; cada lote tiene un área inspeccionada distinta (nᵢ variable), por lo que — igual que en el Caso 5 — los límites varían lote a lote.

Área: variable (nᵢ por lote)m: 20 lotes (M1/M2 alternados) Fórmula: ū = Σc/ΣnLímites: ū ± 3√(ū/nᵢ)

Qué cambia respecto al Caso 5

  • Misma estructura que el Caso 5: calcula primero uᵢ = cᵢ/nᵢ por lote, y ū como el cociente de sumas (no el promedio simple de los uᵢ).
  • Los límites se calculan por lote, igual que en el Caso 5, y se grafican en forma de escalón.
  • Presta atención al patrón de zigzag entre lotes de molde 1 (M1) y molde 2 (M2) al interpretar — no es aleatorio.
